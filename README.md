# The Strange World Of Johnny The Strange Guy

🌐 **Acesse o site:** [johnnythestrangeguy.neocities.org](https://johnnythestrangeguy.neocities.org/)

## Sobre o projeto

Este projeto é um **blog pessoal inspirado na estética da internet dos anos 2000 a 2010**, resgatando o visual e a atmosfera da antiga Web.

A proposta é trazer de volta a personalidade dos sites daquela época, com referências à estética retrô, ao Windows 95, aos GIFs animados, aos cursores personalizados e aos elementos visuais que marcaram a internet do início dos anos 2000.

Mais do que um site, é um pequeno espaço pessoal na web, feito para expressar criatividade, compartilhar ideias e preservar um pouco da nostalgia da internet antiga.

## Objetivo

Criar uma experiência que lembre a internet de uma época em que os sites tinham identidade própria, layouts experimentais e muita personalidade, priorizando a expressão individual em vez dos padrões modernos de design.
